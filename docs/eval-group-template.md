## How the group works

- The Master supplies a bounded question, the artifact or decision, relevant evidence and the expected return. Use the group when a different vantage point or a consequential check can improve the work.
- For a relational eval, one peer takes the sovereign's position and the other takes the relevant counterpart's. Choose viewpoints suited to the case. Check what each actor knows, wants, offers, risks and can decide. When first impressions matter, capture the counterpart's cold read before sharing the maker's rationale. In reciprocal work, giver and active receiver describe how peers contribute and take turns.
- The lead or designated harness reviewer checks the selected contract, current steering, original evidence and relevant lived experience. Bring decision-changing context into the discussion while the work can still change. Ask a pointed question or give a supported correction, and say what it changed or confirmed.
- Return the findings, evidence and unresolved differences to the Master. Use qualitative judgement and quantitative checks where they help answer the question. Record consequential decisions and reasons with the existing case or decision owner.

## Set up and verify

Apply the desired settings through the owning runtime's supported controls and read back the room, purpose, notes, routing and members. Have each participant open the required sources from its actual group context. For lead routing, send one unaddressed test post and observe who receives it. Run one bounded Master-to-room handoff and return on real work. Record the result, source access and any remaining gap with the existing deployment or case record.
