# Getting started

This is the minimum setup path for the private alpha. The package contains operating guidance; it is not a one-click installer. Runtime-specific installation and useful paired operation remain under development.

## Supply the accepted package

Choose an accepted Git revision and keep its files together. Start with [README](../README.md), [SOUL](../SOUL.md) and [AGENTS](../AGENTS.md). Follow their relative routes to the methods and references relevant to the assignment. A skill's `SKILL.md` does not include its linked references automatically.

Configure instruction loading using the intended runtime's supported mechanism. Record the supplied revision and preserve existing personalisation and specialist procedures. A repository update does not update an installation automatically. [Hermes file conventions](https://hermes-agent.nousresearch.com/docs/user-guide/which-file-does-what) are a runtime reference, not a dependency on the creator's setup history.

## Supply private personal context

Create or adapt the [Sovereign Profile template](sovereign-profile-template.md) in a chosen private home outside the reusable package. Put established personal answers and communication preferences directly in that profile or its internally linked detail. Give the working context access to the relevant files. Ordinary profile use should not require access to the creator's Notion workspace.

Keep credentials outside the profile. Exact submitted documents, correspondence and changing case facts remain with their case owners. Supply those inputs when an assignment needs them, with applicable authority and the current checkpoint. An external service is optional until the work depends on its live records.

## Begin useful authorised work

Give the agent a concrete outcome, relevant sources, authority and destination. Existing [Perception Check](../skills/perception-check/SKILL.md) guidance can help establish what needs attention, using sources actually available. Partial context is compatible with useful work; report a material gap and continue unaffected work.

An enduring role also needs its individual contract, the [common operating contract](operating-contract.md), current brief and two actual participating contexts. Supply both with the relevant accepted basis. Reading a definition does not instantiate the pair. Temporary workers do not become enduring roles.

Apply proportionate review to the actual result and inspect saved changes when saving is part of the assignment. Keep what was prepared, accepted, installed and observed distinct. Retain decisions and the next useful action in the existing work record so the assignment can continue.
