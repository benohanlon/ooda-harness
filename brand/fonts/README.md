# Bundled fonts

The kit uses **IBM Plex Mono** Regular 400/Medium 500 for headers and metadata, **Barlow Condensed** Regular 400/Bold 700/Black 900 for quotations, role titles and character names, and **Inter Bold 700** for the human statement and diagram hierarchy.

All files are unmodified and accompanied by their complete SIL Open Font License texts. These are explicit production choices; no exact font identity is inferred from generated raster lettering.

| Files | Original source |
| --- | --- |
| IBMPlexMono-Regular.ttf, IBMPlexMono-Medium.ttf | [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) |
| IBMPlexMono-OFL.txt | Same distribution's OFL.txt |
| Inter-Bold.ttf, Inter-Bold.woff2 | [Official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1) |
| Inter-LICENSE.txt | Same release, LICENSE.txt |
| BarlowCondensed-Regular.ttf, BarlowCondensed-Bold.ttf, BarlowCondensed-Black.ttf | [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/barlowcondensed), retrieved 10 November 2026 |
| BarlowCondensed-OFL.txt | Same distribution's OFL.txt, retained unchanged |

The Plex and Inter files are retained from the earlier kit. The manifest records the current checksums. Install TTFs for desktop editing; the renderer embeds the local dependencies and waits for all fonts and weights to load. No runtime font download is required.
