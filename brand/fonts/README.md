# Fonts

The editable prototypes use **IBM Plex Mono Medium** for identity and supporting lines, **Inter Bold** for the pupil statement and **IBM Plex Mono Regular** for kit metadata. These are template choices. The approved v1.2 image has flattened, generated typography.

Both families are distributed under the SIL Open Font License 1.1. The complete licence texts are included, unchanged. The fonts are unmodified.

| File | Source |
| --- | --- |
| IBMPlexMono-Regular.ttf | [Google Fonts distribution](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-Regular.ttf) |
| IBMPlexMono-Medium.ttf | [Google Fonts distribution](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/IBMPlexMono-Medium.ttf) |
| IBMPlexMono-OFL.txt | [Distribution licence](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt) |
| Inter-Bold.ttf | [Official Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), extras/ttf/Inter-Bold.ttf |
| Inter-Bold.woff2 | Same release, web/Inter-Bold.woff2 |
| Inter-LICENSE.txt | Same release, LICENSE.txt |

The Plex files were originally retrieved on 5 October 2026 for the Survival of the Sovereign kit. The Inter files were extracted from its retained official release archive. This kit reuses those unmodified files and records their checksums in the manifest.

Install the TTFs before editing in a desktop vector application. The included renderer embeds the bundled fonts into its temporary browser document, so it does not require system font installation or font downloads.
